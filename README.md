### Projects

**[Rally](https://github.com/chrisgarceau6-dev/rally)** · **[live](https://rally-kappa-five.vercel.app)** — A mobile-first marketplace for
UMass students, built around dorm-room swaps. A reciprocal matching algorithm ranks
suggested swaps by area, room type, building, gender preference, and recency. Launched to
**58 listings from ~50 students across all five residential areas in the first week.**

The whole flow works without accounts — posting generates a one-time management code
stored as a salted hash, so students can post, extend, or delete without signing up.
Listings expire after 14 days by design, so the board clears between cycles instead of
filling with stale posts. Currently rebuilding for fall with rides, sublets, marketplace,
errands, and lost & found planned.
*Next.js · React · TypeScript · Tailwind · Supabase · Vercel*

**[AI Options Terminal](https://github.com/chrisgarceau6-dev/ai-options-terminal)** · **[live](https://sincere-charisma-production-992c.up.railway.app)** — A
real-time product that helps retail options traders find high-probability setups without
manual research. Auto-scans 500+ S&P 500 stocks and ETFs three times per trading day, uses
AI to generate plain-English trade theses, and surfaces the best opportunities through a
custom scoring model and alert system. Includes live market regime detection, earnings
risk flagging, a Monte Carlo simulator, and sector-level analysis.
*React · Node.js · PostgreSQL · Tailwind · Anthropic API*

**[Kalshi Trading System](https://github.com/chrisgarceau6-dev/kalshi-trading-audit)** — An
automated trading system on Kalshi's 15-minute crypto markets, live since July 2026. It
runs unattended: finds its own signals, places and reconciles its own orders, holds every
position to settlement. If it cannot prove what it is holding, it halts instead of
guessing. 111 automated tests cover the order path and every risk limit.

Every change ships with a decision rule fixed *before* deployment, including the
conditions that would require killing it. That has already retired a feature of mine that
backtested well and turned out to be rejecting profitable trades. **The linked repo is the
writeup, not the strategy** — what I found auditing my own measurements.
*Python · NumPy · GitHub Actions*
